## How to View These Files

### For Obsidian Users
These notes are explicitly designed to be used as an **[Obsidian](https://obsidian.md/)** Vault. If you are an Obsidian user, simply download this repository and open the folder in Obsidian to instantly navigate links, view dynamic tables, and see embedded source images.

### Viewing Directly on GitHub
If you don't want to install Obsidian, you can still easily read all of the notes right here on GitHub! However, there are a few things you should know about how the text is formatted:

When you read the notes on GitHub, you might see text that looks like this:
`![[Author - Book - Location#Author - Book - Location]]`

This is a special link telling Obsidian to automatically insert a picture or text from another file. Since GitHub doesn't automatically load the picture for this type of link, you just have to follow it manually! Here is how to do it:

1. **Look at the name inside the brackets:** In the example above, the name of the file is `Author - Book - Location`. It is the text that comes right before the `#` symbol.
2. **Find that file:** Simply navigate around the repository folders (usually inside the `333 Sources` or `111 Source Sheets` folders) and click on the file with that exact name.
3. **What does the `#` mean?:** The `#` symbol just points to a specific **Heading** inside that file. So if you see `![[Note Name#Background Info]]`, it just means you should open the file called `Note Name`, and then scroll down to the "Background Info" section of that page.

## 📝 Commit Message Styling

For contributors, we use a specific emoji-based styling guide for our commit messages to keep the history organized. The commit message should always just be the name of the source sheet.

* **⏳ Incomplete Sheets:** Use the hourglass emoji for source sheets that we started but didn't finish today.
  * *Example:* `⏳ Halacha - under 20`
* **🎓 Completed Sheets:** Use the graduation cap emoji for source sheets that were newly created and completed.
  * *Example:* `🎓 Gemara - Maseches Kesubos`
