### רב יעקב בצלאל זולטי - משנת יעב''ץ - או''ח ס׳ ל''ט
The [['מח]] is about weather the people could have done it by themselves or not
The reason this is permitted is because that is not a normal way to do it.
This is a שבת only rule - things have to be done in the normal manner
